# BoardState Lite Original Cinematic Storyboard

This production is an original motion-graphics commercial. It does not use raw BoardState Lite application recordings as its visual foundation. The canvas is intentionally marked `GAMEPLAY VISUALIZATION` so conceptual visuals are not mistaken for literal application screenshots.

| Time | Visual | Verified claim | On-screen copy |
| --- | --- | --- | --- |
| 00:00-00:06 | Original overhead-style Commander table with abstract permanent cards, life, damage, and counters | Lite is a physical-game companion | Commander gets complicated. Keeping track of it shouldn't. |
| 00:06-00:16 | Brand reveal, life and commander-damage panels, Full-Screen Life-inspired composition | Life, commander damage, and presentation mode | Your game. One clear view. |
| 00:16-00:29 | Five original permanent visualizations receive animated +1/+1 badges from one central action | Deterministic counter bookkeeping | Automatic counter distribution |
| 00:29-00:40 | Original card-choice visualization with explicit player-control framing | Player remains authoritative for choices; no unsupported target/sacrifice claim | Player-controlled when it counts |
| 00:40-00:51 | Ability Focus grid, selected permanent, activated ability text, used state, next-turn recovery | Ability Focus and turn-scoped usage tracking | Know your options. Track every activation. |
| 00:51-00:59 | Counter state review, Undo, restored prior state | Transaction-level correction/Undo | Correct. Continue. Play. |
| 00:59-01:08 | Dungeon route, initiative transfer/status, custom counter labels | Dungeons, Initiative, customizable player counters | More than a life counter |
| 01:08-01:15 | Logo symbol resolves from energy; truthful CTA | Product identity | Play the cards. Let Lite handle the bookkeeping. |

## Production notes

- No target-selection, sacrifice-selection, Echo, ARGUS, or offline-recovery claim is included because those paths were not live-verified in the available evidence set.
- The ability example is a verified once-per-turn Life Relic-style activation represented as original card art and typography, not a copied card face.
- The end card uses `COMING SOON` because no verified public download destination is present in the repository.
- `GAMEPLAY VISUALIZATION` is retained as a persistent disclosure for conceptual shots.
